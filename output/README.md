# Recursos de demostración

Estos archivos se conservan porque los scripts y pruebas los utilizan:

- `comprobantes-demo/`: imágenes ficticias de SINPE y transferencia.
- `pdf/`: comprobantes PDF ficticios correspondientes a pagos DEMO.

No son respaldos de SQL Server ni archivos de usuarios. Los comprobantes reales
se guardan en SQL Server y se consultan mediante la API autorizada.

Las versiones PNG y PDF son formatos diferentes utilizados para probar el visor;
no se consideran duplicados. Para generar o adjuntar los ejemplos, consultar
[db/demo/README.md](../db/demo/README.md). Las capturas de revisión se guardan
en carpetas temporales excluidas de Git.
